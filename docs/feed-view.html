개요

피드 게시글 하나를 자세히 보여주는 화면이다. 목록 카드를 클릭하면 이 화면으로 이동한다. 현재는 조회와 댓글 작성만 지원하며, 수정·삭제 기능은 아직 이 화면에 없다.

화면 설명

1 제목
  • 제목 출력
2 작성자/등록일시
  • 작성자, 등록일시 출력
  • 자유게시판·공지사항과 달리 수정일시·조회수는 노출하지 않음
3 내용
  • 등록 내용 출력
4 대표 이미지
  • 첨부파일 목록(다운로드 링크) 형태가 아니라, 내용 바로 아래에 이미지를 직접 렌더링해서 보여줌
  • 피드 게시글은 이미지만 첨부 가능하며 최대 1장으로 제한 (자유게시판·공지사항과 달리 문서 파일·다중 첨부 불가)
  • 등록된 이미지가 없으면 이 영역 자체가 노출되지 않음
5 좋아요
  • 이미지 아래·댓글 위에 위·아래 구분선과 함께 별도 줄로 노출해 눈에 잘 띄게 함 (목록 화면처럼 텍스트 옆 작은 표시가 아님)
  • 하트 아이콘 + "좋아요" 텍스트 + 개수를 큰 버튼 형태로 표시
  • 클릭해서 좋아요를 남기는 토글 기능은 아직 이 화면에는 없고, 개수만 노출
6 댓글
  • 댓글이 등록된 경우 목록으로 출력, 없으면 댓글 입력 영역만 표기
  • 표기 항목: 작성자, 등록일시, 댓글 내용
  • 최근 등록한 댓글이 하단에 출력됨
  • 입력 영역: 작성자, 댓글 내용 — 등록 클릭 시 새로고침 없이 목록 맨 아래에 바로 추가됨
  • 작성자·내용 중 하나라도 비어 있으면 등록되지 않고 안내 문구 노출
  • 게시판 공통 댓글 기능을 그대로 사용 (자유게시판·공지사항과 동일한 API)
