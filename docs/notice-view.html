SPEC 왼쪽 화면의 각 요소가 어떻게 동작하는지에 대한 설명

개요

공지사항 게시글의 상세 내용을 조회하는 화면이다. 댓글 등록, 게시글 수정·삭제 이동도 이 화면에서 이루어진다.

화면 설명

1 제목
  • 제목 출력
2 등록 정보
  • 등록일, 등록자 출력
  • 조회수
3 모임 정보
  • 내용보다 위, 제목 바로 아래에 위치
  • 일시, 장소, 책, 읽어올 범위, 참가비용을 항목별로 구분해서 출력
  • 책·참가비용 항목은 각각 책이름·출판사 / 금액·비고 두 입력란의 값을 '/'로 구분해 한 줄로 출력 (별도 라벨 표기 없음)
  • 읽어올 범위 항목은 시작 페이지·끝 페이지 두 입력란의 값을 받아 'N쪽 ~ M쪽' 형식으로 출력
4 내용
  • 등록 내용 출력
5 첨부파일
  • 2개 이상 표시 가능
  • 표기: 파일명 + 확장자
  • 클릭 시, 다운로드
  • 해당 첨부의 서버 URI 링크가 아닌, 바이너리 다운로드 형태로 구현되어야 함
6 댓글 내용
  • 댓글이 등록된 경우 출력
  • 등록된 댓글이 없을 경우, 댓글 입력 영역만 표기
  • 표기 항목: 등록자 이름, 등록일, 댓글 내용
  • 최근 등록한 내용이 하단에 출력
  • 입력 영역: 작성자, 댓글 내용
7 삭제
  • 비밀번호 확인 레이어 노출
  • 비밀번호 입력 후 삭제
