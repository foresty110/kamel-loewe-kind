SPEC 왼쪽 화면의 각 요소가 어떻게 동작하는지에 대한 설명

개요

철학 커뮤니티 회원들이 가볍게 짧은 글과 사진을 올리고, 좋아요·댓글로 반응하는 피드 형태의 목록 화면이다. 기존 자유게시판(표 형태)과 달리 카드가 세로로 이어지는 레이아웃이며, 카테고리 구분은 없다.

화면 설명

1 글쓰기
  • 목록 상단 고정, 클릭 시 피드 작성 화면으로 이동
2 작성자/시간
  • 작성자는 로그인 없이 직접 입력한 이름 (자유게시판과 동일)
  • 작성 시각은 상대 시간으로 표기 (예: 3분 전, 1시간 전, 어제)
3 제목
  • 제목 출력, 카드 클릭 시 상세 화면으로 이동
4 본문 미리보기
  • 3줄까지 표시하고 넘으면 말줄임(…) 처리, 전체 내용은 상세 화면에서 확인
5 대표 이미지
  • 기존 첨부파일 기능으로 등록된 이미지가 있을 때만 표시
  • 여러 장 첨부했어도 카드에는 첫 번째 이미지 1장만 썸네일로 노출
6 좋아요
  • 클릭할 때마다 좋아요/취소 토글, 서버는 카운트 값만 증가·감소
  • 로그인이 없어 "내가 눌렀는지"는 브라우저(로컬 저장소) 기준으로만 하트가 채워진 상태로 표시됨
  • 기기·브라우저가 바뀌면 좋아요 표시 상태는 초기화됨 (카운트 자체는 서버 값 유지)
7 댓글 수
  • 댓글 목록은 상세 화면에서만 확인 가능, 목록에는 개수만 표시
8 더 불러오기
  • 페이지네이션이 아닌 무한스크롤 방식, 화면 하단에 닿으면 다음 게시글을 이어서 불러옴
  • 마지막으로 불러온 게시글을 기준으로 다음 게시글들을 가져옴 (페이지 번호 방식 아님)
  • 더 불러올 게시글이 없으면 로딩 영역 대신 "마지막 게시글입니다" 문구로 대체
